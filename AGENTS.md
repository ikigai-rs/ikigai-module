# AGENTS.md

`ikigai-module` is the dynamically-loadable module format for the ikigai kernel: a module mounted
behind a few IRI prefixes, with its callbacks resolved against the host's kernel.

- Read [ACCESSIBILITY.md](ACCESSIBILITY.md) before any change to output people read: messages,
  pages, terminal text.
- Security reports go through [private vulnerability
  reporting](https://github.com/ikigai-rs/ikigai-module/security/advisories/new), never a public
  issue.
- Use American spelling (behavior, color, labeled, artifact).
